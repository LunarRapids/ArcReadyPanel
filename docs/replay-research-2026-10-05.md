# 2026-10-05 即时回放低开销研究

本轮确认：应用分配纹理的直接编码路径可减少应用层转换后的GPU复制。本进程3D引擎占用在本次1080p60测试中明显降低，但CPU和封装功耗仍受短测波动影响，不能给出稳定降幅、绝对零拷贝或低于OBS的结论。

环境：Intel Core Ultra X7 Processor 358H、Intel Arc B390 GPU，驱动32.0.101.9033，Windows平衡电源方案。后台已有ArcReadyPanel运行，未停止用户进程；不是隔离实验室条件。输入为GPU生成的循环变色画面，固定60FPS、20Mbps、硬件AV1、LowPower、AsyncDepth=1。不包含游戏负载、整套桌面采集、系统声音及回放保存。因此这些值不是游戏FPS损失或整机墙上功率。

每个路径以copy/direct/direct/copy顺序测量，排除每阶段前三秒热身。第一轮每阶段15秒、有效12秒；追加进程GPU计数轮每阶段10秒、有效7秒。每阶段帧数/包数吻合，无测试调度超时。第一轮GPU百分比为适配器所有进程汇总；追加轮额外按当前进程PID筛选，不能混为一谈。

| 测试 | 指标 | 复制路径 | 直接路径 |
|---|---|---:|---:|
| 1080p60/12秒 | 进程CPU时间 | 120.445 ms/s | 96.354 ms/s |
| 1080p60/12秒 | 平均编码调用耗时 | 6.538 ms | 5.756 ms |
| 1080p60/12秒 | 封装功率 | 4.551 W | 4.669 W |
| 4K60/12秒 | 进程CPU时间 | 110.026 ms/s | 103.516 ms/s |
| 4K60/12秒 | 平均编码调用耗时 | 11.054 ms | 10.013 ms |
| 4K60/12秒 | 封装功率 | 4.881 W | 4.338 W |
| 1080p60/7秒追加 | 进程CPU时间 | 107.139 ms/s | 110.494 ms/s |
| 1080p60/7秒追加 | 平均编码调用耗时 | 6.257 ms | 6.093 ms |
| 1080p60/7秒追加 | 封装功率 | 5.331 W | 3.999 W |
| 1080p60/7秒追加 | 本进程3D引擎占用 | 1.545% | 0.594% |

追加轮的进程3D占用从约1.55%降至0.59%，这是最清晰的信号。CPU时间第一轮下降、追加轮略升；1080p封装功率第一轮略升、追加轮下降，说明短测受系统负载影响明显。不能挑选某一轮作为功耗宣传数字。封装与GPU能耗口径可能重叠，不相加。VideoEncode PDH计数本机未暴露，记NA，不能当成0；Copy计数接近0也不能证明驱动内部没有通过其它引擎复制。

Windows Graphics Capture备用捕获请求原为半帧间隔（最高请求两倍目标更新率）。改为完整间隔后30FPS十秒测试仅258帧，原280帧，故不采用。最终选择75%帧间隔、25%时间戳容差，实测30FPS278帧、60FPS549帧，对照旧版280/535帧，队列覆盖丢帧计数均为0。实际窗口源约58FPS，不强制补重复画面到60FPS。默认整桌面DXGI路径未改。RAM/磁盘缓存、AV1+系统声音、默认声音设备重开、保存、缓存释放测试通过。

GPU内部复制验证：WPR GPU追踪启动返回0xc5585011，当前进程未提升，Windows拒绝启用系统性能分析权限。再次检查WPR未处于记录状态。未产生可分析GPU追踪，不宣称验证了驱动内部零拷贝。微软的[GPUView说明](https://learn.microsoft.com/en-us/windows-hardware/drivers/display/using-gpuview)给出GPU/CPU和DMA队列分析方法；后续需管理员授权的GPU追踪及更长、受控的功耗ABBA测试。桌面采集释放时机可参考[ReleaseFrame官方说明](https://learn.microsoft.com/sv-se/windows/win32/api/dxgi1_2/nf-dxgi1_2-idxgioutputduplication-releaseframe)，目前未凭理论改动默认DXGI路径。

可复现工具：构建ReplayPathBenchmark，执行`ReplayPathBenchmark.exe 1920 1080 60 15`或`3840 2160 60 15`，标准输出为CSV。工具不进入便携包，不增加软件后台占用。原始数据保存在research-data-2026-10-05目录。追加测量包含单独PDH查询，其采样开销同样包含在进程CPU时间中。
