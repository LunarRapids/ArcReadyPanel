# ArcReadyPanel 0.2.18 捕获节奏与功耗研究

继续使用0.2.17的应用分配NV12纹理直达Intel AV1编码路径，不增加渲染循环、后台采样、软件编码或新的运行时依赖。

Windows Graphics Capture备用路径的MinUpdateInterval从目标帧间隔50%调整为75%，保留25%调度余量，并在时间戳门限中允许相同幅度的抖动。目标60FPS时请求更新上限从120降为80FPS，目标30FPS从60降为40FPS；这是请求上限，不代表实际捕获频率。整个桌面的默认DXGI Desktop Duplication路径保持不变。

直接设置100%帧间隔曾使30FPS测试的有效帧数从280降至258，因此未采用。75%间隔实测278帧，60FPS实测549帧；对应旧版为280/535帧，均为10秒连续动态窗口测试。窗口源约58FPS，设置值为上限，不强制重复编码相同画面补帧。

新增独立ReplayPathBenchmark测试工具，固定帧率、ABBA路径顺序、每阶段排除3秒热身，测量进程CPU时间、编码耗时、封装和GPU功率、适配器及本进程GPU引擎占用。它不打包进应用，不增加常驻资源。详细结果见replay-research-2026-10-05.md；不能据有限短测试宣称稳定功耗降幅或低于OBS。
